# Hari Mohan Sai Vinay Mavuri — Portfolio

Personal portfolio website of **Hari Mohan Sai Vinay Mavuri**, Salesforce Developer.

Built with plain HTML, CSS, and JavaScript — no build step required.

## Run locally
Open `index.html` in any browser.

## Deploy (GitHub Pages)
1. Push this repo to GitHub.
2. Repository → **Settings** → **Pages**.
3. Source: **Deploy from a branch** → Branch: `main` → `/root` → **Save**.
4. Your site will be live at the Pages URL shown there.

## Structure
- `index.html` — page content and structure
- `styles.css` — styling and animations
- `script.js` — interactions (nav, reveals, counters)
- `Hari_Mohan_Sai_Vinay_Mavuri_Resume.pdf` — downloadable resume
